# Portal Lembaga Pendidikan Ma'arif NU PBNU

![LP Ma'arif NU](./assets/img/LOGO-MAARIF-WEB.jpg)

Portal resmi Lembaga Pendidikan Ma'arif Nahdlatul Ulama PBNU - Platform digital yang menaungi lebih dari 24.000 satuan pendidikan Islam berkualitas di seluruh Indonesia.

## 🌟 Tentang Kami

Lembaga Pendidikan Ma'arif NU PBNU adalah organisasi otonom Nahdlatul Ulama yang bergerak di bidang pendidikan Islam sejak tahun 1926. Kami berkomitmen untuk:

- 🎓 **Pendidikan Berkualitas**: Menyediakan standar pendidikan tinggi dengan kurikulum terintegrasi
- 🤲 **Akhlak Mulia**: Membentuk karakter islami dan nilai-nilai kebangsaan 
- 💡 **Inovasi Pembelajaran**: Menerapkan metode pembelajaran modern dan teknologi terkini
- 🌍 **Jangkauan Nasional**: Melayani pendidikan di 34 provinsi Indonesia

## 📊 Statistik Pendidikan

| Kategori | Jumlah |
|----------|--------|
| **Satuan Pendidikan** | 24,000+ |
| **Peserta Didik** | 8 Juta+ |
| **Tenaga Pendidik** | 600,000+ |
| **Pengalaman** | 98 Tahun |

## 🚀 Fitur Portal

### 🌐 Portal Utama
- Informasi kebijakan pendidikan terbaru
- Berita dan pengumuman resmi
- Direktori lengkap sekolah Ma'arif
- Resource dan materi pendidikan

### 📋 SIPINTER (Sistem Informasi Pesantren Terintegrasi)

- Monitoring kualitas pendidikan real-time
- Laporan statistik komprehensif
- Manajemen data siswa dan guru

Portal ini dibangun menggunakan teknologi modern:

- **Frontend**: HTML5, CSS3, JavaScript ES6+

- **Font**: Inter & Poppins (Google Fonts)
- **Icons**: Font Awesome 6.4.0
- **Animations**: Animate.css 4.1.1
- **Backend**: PHP

## 🚀 Instalasi & Penggunaan

1. **Clone Repository**
   ```bash
   git clone https://github.com/faisolarifin/beranda-lpmaarif.git
   ```

2. **Setup Server**
   - Pastikan PHP 7.4+ terinstall
   - Jalankan dengan web server (Apache/Nginx) atau PHP built-in server
   ```bash
   php -S localhost:8000
   ```

3. **Akses Portal**
   - Buka browser dan kunjungi `http://localhost:8000`
